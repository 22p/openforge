API

OpenForge speaks the Attended Sysupgrade API. Point owut, LuCI or the OpenWrt firmware selector at this server.

GET /json/v1/overview.json branches, versions, server
GET /json/v1/branches.json releases and targets
GET /api/v1/revision/{version}/{target}/{subtarget} upstream revision
POST /api/v1/build request a custom image
GET /api/v1/build/{request_hash} build status and result
GET /store/{request_hash}/{image} download artifact
